## Приоритет источников при расхождении

1. **Miro** — актуальный дизайн и требования (проверено: на доске есть экраны, которых нет
   ни в BRD, ни в модели данных).
2. **Модель данных (docx)** — свежее BRD по дате, но описывает Telegram через **Bot API**
   (таблица `bots`, `token_ref`, `webhook_secret`, `telegram_updates.update_id`), тогда как
   Miro описывает подключение **личных аккаунтов по номеру телефона с кодом и облачным
   паролем** — это MTProto. В этой части модель данных неверна.
3. **BRD v2.0** — самый старый. Расходится с Miro по валюте (тенге против рублей),
   ролям (три против двух), воронке, SLA, справочнику услуг. Использовать только как
   источник домена, не требований.

## Форматы

- **PDF / DOCX** — читаю нормально, отдельная конвертация не нужна.
- **XLSX / CSV** — годится для выгрузок данных и справочников.
- **Скриншоты** — только как дополнение к тексту, не вместо него.
